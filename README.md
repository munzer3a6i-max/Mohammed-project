# 🏢 Real Estate Management System

نظام ويب لإدارة بيع القطع العقارية: تسجيل القطع، متابعة المدفوعات والمبالغ المتبقية، والبحث والتعديل والحذف.
مشروع تخرج مبني بـ **PHP** و **MySQL**.

## ✨ المميزات
- تسجيل دخول بكلمة مرور مشفّرة، وحماية كل الصفحات من الدخول بدون تسجيل
- لوحة تحكم بإحصائيات: عدد القطع، إجمالي القيمة، المدفوع، المتبقي، ونسبة التحصيل
- إضافة / تعديل / حذف / بحث / عرض القطع
- حساب المبلغ المتبقي تلقائياً (في المتصفح وفي السيرفر)
- منع تسجيل نفس القطعة مرتين (نفس رقم المخطط + رقم القطعة)
- بحث جزئي بالاسم أو رقم المخطط، وفلتر سريع في جدول القطع
- تصميم عصري متجاوب مع الجوال
- حماية من: SQL Injection و XSS و CSRF

## 🔐 مثلث الأمان CIA
| المبدأ | معناه | ما تم تطبيقه |
|-------|-------|--------------|
| **C — Confidentiality (السرية)** | البيانات لا يراها إلا المصرّح له | تسجيل دخول إجباري، تشفير كلمات المرور (bcrypt)، قفل الحساب بعد 5 محاولات خاطئة، خروج تلقائي بعد 15 دقيقة، كوكيز آمنة، حماية XSS، تغيير كلمة المرور |
| **I — Integrity (السلامة)** | البيانات صحيحة ولا تتغير بدون علمنا | Prepared Statements، رموز CSRF، التحقق من البيانات في السيرفر، قيود CHECK و UNIQUE في قاعدة البيانات، سجل العمليات (Audit Log) |
| **A — Availability (التوافر)** | البيانات متاحة وقت الحاجة | نسخ احتياطي بضغطة (CSV / SQL) واسترجاع، صفحات خطأ مرتبة مع تسجيل الأخطاء، فهارس لتسريع البحث، قفل مؤقت وليس دائم |

كل هذا معروض في صفحة **Security (CIA)** داخل النظام.

> ⚠️ غيّر كلمة المرور الافتراضية من صفحة Security بعد أول دخول.

## 🛠️ التقنيات
PHP 8 · MySQL · PDO · HTML5 · CSS3 · JavaScript · Boxicons

## 🚀 التشغيل على الجهاز (XAMPP)
1. انسخ مجلد `Real_estate` إلى `C:\xampp\htdocs\`
2. شغّل **Apache** و **MySQL** من XAMPP Control Panel
3. افتح `http://localhost/phpmyadmin` ثم **Import** واختر ملف `database.sql`
4. افتح `http://localhost/Real_estate/`

**بيانات الدخول الافتراضية:**
| الاسم | كلمة المرور |
|------|-------------|
| `majed` | `majed123` |

## 🌐 الرفع على استضافة (InfinityFree)
1. أنشئ قاعدة بيانات MySQL من لوحة التحكم
2. افتح phpMyAdmin واختر القاعدة ثم **Import** الملف `database_hosting.sql`
3. عدّل بيانات الاتصال في `connect.php` حسب بيانات الاستضافة
4. ارفع الملفات داخل مجلد `htdocs`

## 📁 هيكل الملفات
| الملف | الوظيفة |
|------|---------|
| `connect.php` | الاتصال بقاعدة البيانات |
| `functions.php` | الدوال المساعدة (الحماية، التحقق، الرسائل) |
| `header.php` / `footer.php` | الأجزاء المشتركة (القائمة الجانبية والتذييل) |
| `table.php` | جدول عرض القطع المشترك |
| `block_form.php` | نموذج بيانات القطعة المشترك |
| `MinePage.php` | تسجيل الدخول |
| `Page.php` | لوحة التحكم |
| `Add.php` | إضافة قطعة |
| `Update.php` → `Up.php` | البحث ثم تعديل قطعة |
| `Delet.php` → `Delete.php` | البحث ثم حذف قطعة |
| `Find.php` | البحث بالاسم أو رقم المخطط |
| `Show.php` | عرض كل القطع |
| `Security.php` | صفحة الأمان CIA: تغيير كلمة المرور، النسخ الاحتياطي، سجل العمليات |
| `Backup.php` | تنزيل النسخة الاحتياطية |
| `Exit.php` | تسجيل الخروج |
| `style.css` / `app.js` | التنسيق والجافاسكربت |
| `database.sql` | إنشاء قاعدة البيانات (XAMPP) |
| `database_hosting.sql` | نسخة قاعدة البيانات للاستضافة |
